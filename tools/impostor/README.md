# Запекание леса для Godot (импосторы)

Деревья, кусты, трава, пни, брёвна, корни и камни в Godot-версии — это «импосторы»:
высокодетальные модели, заранее отрендеренные под угол игровой камеры (ортогональная, 46.8°)
в две картинки:

- `<имя>_albedo.png` — цвет без освещения (RGBA, альфа — вырез листвы);
- `<имя>_ndt.png` — R,G: нормаль в осях камеры, B: глубина относительно точки земли (±R м), A: затенённость неба (AO, 10 направлений света с тенями).

В игре (`godot/shaders/impostor.gdshader`) по ним считается настоящее освещение солнцем,
тени, глубина каждого пикселя (боец заходит за ствол и под крону). Камера в игре не вращается,
поэтому разницы с полной 3D-моделью не видно, а нагрузка — как у картинки.

Модели: Poly Haven (CC0) — ели, сосны, лиственные, подрост, кусты, папоротник, крапива, трава,
мох, цветы, пни, брёвна, ветки, корни, камни; берёза/дуб/осина/сухостой — генератор EZ-Tree (MIT).

## Как пересобрать
```bash
cd <папка с node_modules three + @dgreenheck/ez-tree>   # см. tools/treegen/README.md
python3 dl_ph.py 2k fir_tree_01 pine_tree_01 ...          # модели Poly Haven в plants/
python3 -m http.server 8791 &
python3 bake.py specs_all.json imp_all                    # ~1 ч на все 134 варианта
cp imp_all/* ../../godot/assets/imp/
```
`specs_all.json` — какая модель, вариант (узел), высота/масштаб, поворот, категория.
`preview.py out.jpg имя1 имя2 …` — быстрый просмотр с освещением.
