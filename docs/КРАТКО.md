# Кратко о проекте (читать первым)

Мобильная изометрическая выживалка, Godot 4.3, папка `godot/`. Владелец тестирует на телефоне.

## Правила
- Отвечать коротко, по-русски.
- Сначала замер, потом правка. Одна проблема за раз.
- «Пока обсуждаем» — ничего не менять.
- Только Blender и Godot. Модели реалистичные.
- После правки: запись в `CHANGES_DRAFT.md`, строка в `CLAUDE.md`, обновить этот файл, коммит в `main`, ссылка на APK:
  https://github.com/emrysmxo-maker/survival-game/releases/download/godot-latest/survival-godot.apk
