### 2. Внёс правку в `godot/scripts/player.gd`
**Коммит:** `b9bc88f47bab1e3a85db3317f1f44511511b3918`

**Проблема:** При беге вперёд + стрельбе назад ноги и корпус разворачиваются на 180° одновременно → "шпагат"

**Решение:**
- Ноги остаются по направлению движения (не разворачиваются на 180°)
- Корпус и ствол плавно следят за целью отдельно
- Поворот разделён на два этапа:
  1. Определяется, нужно ли "пятиться" (rel > REACH)
  2. Если пятиться — ноги остаются как есть, только корпус доворачивает с ограничением скорости
  3. Когда цель почти сзади (> 90°) — используется пошаговый поворот (сначала 50% скорости, потом до полной)

**Diff (главное):**
```gdscript
# БЫЛО (строка 268):
if backpedal:
    legs = wrapf(move_yaw + PI, -PI, PI)

# СТАЛО:
if backpedal:
    legs = move_yaw  # ноги остаются как есть!

# БЫЛО (строка 275-280):
if aiming:
    var d2 := wrapf(legs - yaw, -PI, PI)
    if absf(d2) > 2.9:
        # только обработка крайних углов

# СТАЛО:
if aiming:
    var d2 := wrapf(legs - yaw, -PI, PI)
    if backpedal:
        var body_target := wrapf(aim_world - yaw, -PI, PI)
        var t := clampf(absf(body_target) / (PI * 0.75), 0.0, 1.0)
        var max_step := BODY_TURN_RATE * dt * lerpf(0.5, 1.0, t)
        d2 = clampf(body_target, -max_step, max_step)
    elif absf(d2) > 2.9:
        # старая логика крайних углов
```
